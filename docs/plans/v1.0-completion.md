## 1. Docs-lite (`orbit.docs`)

Pages belong to projects (the Notion wiki half):
```
module_docs.pages (id, project_id, workspace_id, title, body, created_by, created_at, updated_at)
```
- Rich text stored as markdown; simple editor with preview toggle
- Events: `page.created`, `page.updated` — feeds workflows
- Module manifest `orbit.docs`, installs through the gallery
- UI: "Docs" tab on the project page; page list + editor

## 2. Run pagination

`GET /workflows/{wid}/runs?limit=50&before={runId}` — cursor-based, descending. Default 50.

## 3. Workspace settings

- `PATCH /v1/workspaces/{id}` — rename (owner)
- `DELETE /v1/workspaces/{id}` — delete, cascades everything (owner + confirm)
- UI: settings section on the workspace page

## 4. MCP server

`POST /mcp` — JSON-RPC 2.0 endpoint implementing MCP protocol tools:
- `orbit_create_task`, `orbit_list_tasks`, `orbit_update_task`, `orbit_complete_task`
- `orbit_create_record`, `orbit_list_records`
- `orbit_run_workflow`, `orbit_list_runs`
- `orbit_create_page`, `orbit_search`
- Auth: Bearer token (existing `api_tokens`)
- Each tool call writes an audit row attributed to the token's owner

## 5. Agent identity

```
agents (id, user_id, name, description, token_id → api_tokens, created_at, revoked_at)
```
- Agents are named API tokens with a human-readable identity
- Every audit row that results from an agent's action carries `agent_id`
- Revoking the token kills the agent
- Listed on the API tokens page

## 6. Visual workflow canvas

A drag-and-drop graph editor:
- Nodes rendered as cards with type-specific icons
- Connect nodes by dragging from output handle to input handle
- Branch nodes show yes/no ports
- Property panel below the canvas (JSON editing stays as fallback)
- Save → same PATCH endpoint → draft → validate → ready

## 7. Security audit

- Test every route for auth bypass, tenant isolation, injection
- Verify rate limiting, payload caps, 404 no-leak
- Check CORS, cookie flags, token security
- Document findings

## 8. Install polish

- Final README with clear quickstart
- Compose file reviewed for production defaults
- Backup/restore verified end-to-end
- Tag `v1.0.0`
